# 메일파일럿 Uni 0.3 — 범용 메일 수집기

메일함을 지켜보다가 **선박·항차별 폴더에 첨부를 자동으로 쌓고**, 검수 앱의 **선박 리스트를 스스로 채워 넣는** 프로그램입니다.
선박 이름을 미리 등록할 필요가 없습니다. 메일 제목과 첨부파일 이름에서 선박·항차를 읽어냅니다.

> ⚠ **개인 PC 전용.** 설정 파일(`config.json`)에 메일 비밀번호가 **평문으로** 저장됩니다.
> 공용 PC·공유 폴더에서는 쓰지 마십시오. (아직 암호화 전입니다 — 다음 판에서 암호화합니다.)

**0.3에서 달라진 것 — 아이디·비밀번호만으로 붙습니다.**
회사 메일(후이즈)은 IMAP 을 제공하지 않습니다. 그래서 **POP3** 경로를 넣고 이걸 기본으로 삼았습니다.
앱 비밀번호·2단계 인증을 준비할 필요가 없습니다. **서버에 있는 메일은 지우지 않고 복사만** 해 옵니다.

---

## 설치·설정 3단계

### 1단계 — 실행

파이썬 3.9 이상이 설치된 PC에서 `run_mailpilot.bat` 을 더블클릭합니다. 설정 창이 뜹니다.
(파이썬이 없으면 <https://www.python.org/downloads/> 에서 설치하고, 설치 화면의
"Add python.exe to PATH" 를 반드시 체크하십시오.)

### 2단계 — 메일 계정

| 항목 | 설명 |
|---|---|
| 메일사 | **후이즈/회사메일**(기본) / 네이버 / 한메일(다음) / 지메일 / 직접 입력 — 고르면 방식·서버·포트·SSL 이 자동으로 채워집니다 |
| 이메일·비밀번호 | 자료 메일을 받는 계정 |
| 메일박스 폴더 | 첨부를 쌓을 폴더(예: `G:\내 드라이브\MAILBOX`) |
| 최근 며칠 / 주기 | 기본 7일치를 10분마다 확인 |

메일사별 준비:

- **후이즈/회사메일 (POP3 · 기본)** — 웹메일 **환경설정에서 POP3/SMTP 사용함**인지 확인합니다.
  서버는 `pop.whoisworks.com : 995 (SSL)` 로 자동 입력됩니다.
  **아이디는 메일주소 전체**(예: `office@greenmarine.co.kr`), **비밀번호는 웹메일 로그인 비밀번호**입니다.
  앱 비밀번호·2단계 인증이 필요 없습니다.
- **네이버** — 메일 → 환경설정 → POP3/IMAP 설정 → *IMAP/SMTP 사용* 을 "사용함". 2단계 인증을 쓰면 **애플리케이션 비밀번호**를 넣습니다.
- **한메일(다음)** — 환경설정 → IMAP/POP3 → *IMAP 사용* 켜기.
- **지메일** — **앱 비밀번호 필수**(구글 계정 → 보안 → 2단계 인증 → 앱 비밀번호). 일반 비밀번호로는 접속이 막힙니다.
- **직접 입력** — 방식(IMAP/POP3)·서버·포트·SSL 을 손으로 넣습니다(보통 IMAP 993 / POP3 995).

### 3단계 — firebaseConfig 붙여넣기

앱(검수 앱)에 넣은 것과 **같은** `firebaseConfig` 를 그대로 복사해 큰 입력칸에 붙여넣습니다.
`const firebaseConfig = { apiKey: "...", databaseURL: "..." };` 형태 그대로 붙여넣어도 됩니다.

> 파이어베이스 콘솔에서 **Authentication → 로그인 방법 → 익명**을 켜 두어야 합니다.
> 수집기는 익명 로그인으로 데이터베이스에 씁니다.

마지막으로 **[연결 테스트]** → 메일·파이어베이스 둘 다 OK 인지 확인하고 **[저장]** → **[수집 시작]**.

## 무엇이 어디에 쌓이나

```
{메일박스 폴더}/
  SWDN/2608S/SWDN_2608S_ACTUAL_BAPLIE.edi     ← 선박코드 / 항차 / 첨부
  ATPR/2625E/ATPR 2625E CNTR LIST.xlsx
  _미분류/20260804_연태훼리 2706W CLL 3차/...    ← 판독 실패도 절대 버리지 않습니다
```

- 같은 이름·같은 크기 파일은 다시 받지 않습니다(스킵). 내용이 다르면 `이름 (2).확장자` 로 함께 보관합니다.
- 받는 첨부: `.edi .asc .txt .xls .xlsx .pdf`
- 로그: `mailpilot/logs/YYYYMMDD.txt`

## IMAP 과 POP3 는 무엇이 다른가

| | IMAP (네이버·한메일·지메일) | POP3 (후이즈/회사메일 · 기본) |
|---|---|---|
| 준비 | 메일사에서 IMAP 켜기 + (2단계 인증이면) 앱 비밀번호 | **웹메일에서 POP3 사용함만 확인** — 아이디·비밀번호만 |
| 새 메일 가리기 | 서버에 날짜(SINCE)로 물어봄 | 서버가 주는 **UIDL** 목록을 `pop_uidl_cache.json` 과 대조 |
| 서버 메일 | 그대로 둠 | **그대로 둠** — 지우는 명령(DELE)을 쓰지 않습니다 |
| 판독·적재·앱 등록 | **완전히 같은 코드** | **완전히 같은 코드** |

- POP3 는 서버가 UIDL 을 지원하지 않으면 메일 헤더(Message-ID)의 해시로 대신 가립니다.
- "최근 며칠" 밖의 오래된 메일은 본문을 내려받지 않고 건너뜁니다(다음에 또 확인하지 않도록 목록에만 적어 둡니다).
- `pop_uidl_cache.json` 을 지우면 최근 며칠치를 한 번 다시 받습니다(파일은 이미 있으면 스킵되므로 중복이 생기지 않습니다).

## 데이터베이스에 기록되는 것

| 경로 | 내용 |
|---|---|
| `vessels/{선박코드}` | `name` 선박명, `code` 코드, `discoveredAt` 최초 발견, `lastMailAt` 최근 메일 |
| `collector_heartbeat` | `at` 시각, `version`, `cycleMails/cycleFiles/cycleSkipped` |
| `collect_log/{시각}` | 사이클 요약(최근 50건 롤링) |

## 선박·항차를 읽는 규칙

1. 제목에서 항차 토큰을 찾습니다 — `2630W`, `V.535E`, `V-2643E`, `R083W` 등.
2. 없으면 첨부파일 이름에서 찾습니다.
3. 항차 앞의 **영문 대문자 낱말 최대 2개**를 선박명으로 봅니다(`RE`, `FW`, `MV`, `BAY`, `PLAN`, `LIST` 같은 잡음 낱말은 제외).
4. 선박코드는 낱말마다 **첫 글자 + 이어지는 자음** 2자씩 4자 — `SAWASDEE DENIZ → SWDN`, `STAR MAJESTY → STMJ`, `ATLANTIC PARIS → ATPR`.
   같은 이름은 언제나 같은 코드입니다(`vessels_cache.json` 에 기억).
5. 선박명이나 항차를 못 읽으면 `_미분류` 로 보관합니다.

**아직 못 하는 것**

- 선박명이 세 낱말이면 뒤 두 낱말만 씁니다(`XIN TAI PING` → `TAI PING`).
- 한글 선박명(예: "연태훼리")은 아직 못 읽어 `_미분류` 로 갑니다.
- 두 경우 모두 자료는 남으므로, `_미분류` 폴더를 가끔 확인해 옮기면 됩니다.
