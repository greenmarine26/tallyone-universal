# TallyUni 0.3 (구 Tallyman Master)

(버전 라벨은 build.sh가 src/utils.js APP_VERSION 기준으로 자동 동기화)

평택항 컨테이너선 양하·선적 검수앱 (React/Vite PWA + Firebase).
콘앱(cone.html)·벌크탤리와 함께 단일 통합지침서로 관리됩니다.

## 실행
1. `npm install`
2. `bash build.sh`

## 배포

**배포하기 전에 `DEPLOY.md`를 먼저 읽으세요.** 배포는 클로드가 끝까지 직접 합니다.

작업 규칙·이력은 저장소 루트의 `평택항_검수_통합지침서_3앱통합본_V*.md`(최신 버전)를 따릅니다.
