# TallyOne Universal

> **현재 버전** · TallyUni 0.5

항만 컨테이너선 **검수앱**과 **메일 수집기** 한 벌입니다.
받은 사람이 **환경설정만 하면 자기 회사 앱**이 됩니다 — 코드를 열 일이 없습니다.

- 회사명·로고·모항·**터미널**·직원은 첫 실행 마법사에서 입력합니다.
- 데이터베이스는 회사마다 따로 만듭니다 — 자료가 섞이지 않습니다.
- 선박은 **미리 등록하지 않습니다.** 빈 상태로 시작해 수집기가 메일에서 찾아 채웁니다.

## 무엇을 하는가

| | |
|---|---|
| 검수앱 | 양하·선적 검수, 베이 매트릭스·카고플랜, EDI(BAPLIE·IFCSUM) 판독, 텔리 서류 출력, 수석 대시보드 |
| 콘앱 | 콘·트위스트락 계산 (단일 HTML) |
| 벌크탤리 | 벌크선 철코일 검수 (단일 HTML) |
| 메일 수집기 | 선사 메일의 첨부를 **선박·항차 폴더**로 자동 정리 + 선박 목록 자동 등록 |

## 구성 — 다섯 덩어리

1. **GitHub 저장소** — 소스와 배포(GitHub Pages). 회사별로 fork하지 않습니다. 하나의 소스, 설정만 다릅니다.
2. **검수앱** — React/Vite PWA. 휴대폰 홈 화면에 추가해 앱처럼 씁니다.
3. **콘앱 · 벌크탤리** — 각각 독립 HTML 한 파일.
4. **메일 수집기(MailPilot)** — 파이썬. 윈도우 PC 한 대에 켜 둡니다. → [`mailpilot/`](mailpilot/README.md)
5. **Firebase** — 회사 전용 실시간 데이터베이스 + 익명 인증. 무료 요금제로 시작합니다.

## 빠른 시작 (3줄)

1. **Firebase 프로젝트를 만들고** `firebaseConfig` 를 복사한다 — 15분.
2. **앱 주소를 열어** 첫 실행 마법사 3단계(설정 붙여넣기 → 회사·모항·터미널 → 최초 관리자)를 마친다 — 5분.
3. **수집기를 설치해** 메일 계정과 같은 `firebaseConfig` 를 넣고 [수집 시작] — 10분.

> 📖 **화면 하나하나 따라 하는 문서: [설치안내서](docs/설치안내서.md)**
> (Firebase 15분 절차 · 마법사 3단계 · 메일사별 IMAP 설정 · 두 번째 기기 · 문제 해결)

## 라이선스 · 지원

- 라이선스: _(정하는 대로 채웁니다)_
- 문의: _(연락처를 채웁니다)_
